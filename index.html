Frequently Asked Questions

What file formats are supported?

+

8Direction-3DSpriter supports FBX, GLTF/GLB, and OBJ file formats. All formats support animations, materials, and textures.

What output formats do you support?

+

We export PNG sprite sheets with transparency support. You can choose from various preset resolutions or define custom dimensions for your project needs.

How does the 8-direction rendering work?

+

The tool automatically renders your 3D model from 8 different camera angles (N, NE, E, SE, S, SW, W, NW), perfect for isometric and top-down games. Each direction is captured in your sprite sheet.

Can I control the camera and lighting?

+

Yes! You have full control over camera positioning, angle, and distance. You can also adjust lighting direction, intensity, and color to achieve the perfect look for your sprites.

What is frame skipping?

+

Frame skipping allows you to reduce the number of frames in your sprite sheet. For example, if your animation has 60 frames, you can skip every other frame to create a 30-frame sprite sheet, reducing file size while maintaining smooth animation.

What's the difference between the web and Windows versions?

+

The web version offers 30-day access through your browser, while the Windows version is a downloadable desktop application with lifetime access, offline mode, and faster processing. Both include all features and format support.

Is there a file size limit?

+

The web version has a 100MB file size limit. The Windows desktop version can handle larger files limited only by your system's memory.

Do I get updates?

+

Yes! Both versions receive regular updates with new features and improvements. Windows version users get free lifetime updates.
